# Netflix 双语助手

这是一个可直接加载的 Chrome 扩展，提供多语言文字字幕转简体中文、点击或划选查词、本地生词本。默认使用 Chrome 本地翻译；MyMemory 在线备用需要手动开启。

## 安装

1. 使用桌面 Chrome 138 或以上版本。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录 `/Users/hehaiquan/code/netflix-translate`，该目录中应直接包含 `manifest.json`。
4. 在扩展菜单中固定「Netflix 双语助手」。
5. 刷新已打开的 Netflix 页面。若有其他 Netflix 字幕扩展，先关闭它们的字幕功能，再刷新。

没有 npm 安装、构建或服务器启动步骤。Node 仅用于开发测试，不是插件使用条件。

## 第一次翻译

1. 打开影片，在 Netflix 的音轨与字幕菜单中选择要翻译的原文字幕，例如英语、日语或韩语。
2. 点击工具栏中的插件图标，确认总开关开启。可以使用「自动识别」，也可以手动选择与 Netflix 字幕一致的语言。
3. 如提示需要语言包，点击播放画面右上方的「准备本地翻译」。首次下载可能需要时间，状态栏会显示进度。
4. 模型准备好后，原文在上、中文在下。字幕切换时先显示原文，翻译完成后补上译文。

语言包是否可下载取决于 Chrome 的实际能力、浏览器策略、磁盘及网络状态。浏览器版本符合要求不代表所有语言对都能使用。原字幕为简体中文时不重复生成中文行；繁体中文可以选择相应源语言转为简体。

## 查词与生词本

- 点击原字幕中的词语，或拖选一段短句，打开中文译文浮窗。
- 查词期间暂停播放。关闭浮窗时，只恢复由插件暂停且未切换影片、跳转位置或被用户重新播放的视频；原本已暂停的视频保持暂停。
- 点击「收藏」，保存词语、译文、原句、当前已有的原句译文、影片与播放位置。同一语言下重复收藏同一词语会提示已收藏。
- 从播放画面或插件弹窗打开生词本，可按「今日收藏」或语种筛选，并搜索词语、译文、原文对白、对白译文和影片。支持最近收藏、最早收藏和按词语排序；按 ⌘ K（Windows / Linux 为 Ctrl K）可快速搜索。
- 右上角「导出收藏」可选择 CSV / JSON，导出始终包含全部收藏，不受当前筛选影响。删除前会显示目标词条并要求确认。
- 生词本中的影片链接可以打开对应影片并定位播放时间。影片名称无法从播放器获取时，显示影片编号。
- 点击单词右侧的扬声器可朗读单词或短语，点击「朗读对白」可朗读收藏的原文整句。页面底部会显示当前朗读内容，可点击停止、再次点击原按钮或按 Esc 停止；切换词条、筛选、搜索、排序、删除或离开页面时会停止上一段。
- 发音使用与原文语言匹配的设备本地语音，无需 Key。可用语言和音色取决于系统已安装的语音；缺少对应语音时会在词条内提示，不会改用其他语言或在线语音。

生词只存在当前 Chrome 用户配置的扩展本地存储中。导出文件保留在电脑上；本版不提供导入或云端同步。卸载扩展会删除扩展存储的数据。

## MyMemory 在线备用

在插件弹窗中开启「MyMemory 在线备用」，Chrome 会请求访问 `api.mymemory.translated.net` 的权限。开启后，本地翻译暂不可用时会向该服务发送当前待翻译的字幕或查词文本，不发送生词本、Netflix 账号或浏览器 Cookie。

匿名服务每天限额 5,000 字符，适合短时备用。本地显示的是本扩展已发出请求的估算值，按 UTC 日期切日；服务端可能按共享公网 IP 计数，实际可用量以服务端为准。失败或被中断的请求可能已使用额度，因此本地按已发出字符保守计数。

接口超额后停止自动请求；临时限流时可在弹窗点击「重试在线翻译」。关闭在线备用会停止当前请求并撤回该域名权限。本地翻译可用时始终优先本地。

## 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 等待原文字幕 | 确认已进入影片且 Netflix 原文字幕已开启，等待有对白的片段。 |
| 语言样本不足 | 继续播放几句，或在插件弹窗手动选择源语言。 |
| 当前为图片字幕 | 首版只能读取文字字幕，尝试影片提供的其他文字字幕轨道。 |
| 检测到其他字幕扩展 | 暂停其他字幕扩展并刷新页面，本插件会保留原生显示。 |
| 本地翻译失败或下载失败 | 点击准备按钮重试，确认 Chrome 更新及语言包下载网络正常；也可手动开启在线备用。 |
| MyMemory 今日额度不足 | 保留原文，继续使用本地翻译，等待服务端额度恢复。 |
| 更新扩展后播放页异常 | 在扩展管理页点击刷新本扩展，再刷新 Netflix 标签页。 |
| 字幕重叠或挡住画面 | 调整字号和底部位置，并确认只运行一套字幕扩展。 |

首版支持桌面 Netflix 网页的可读取文字字幕和网页全屏；不包含音频识别、图片字幕 OCR、手机端、系统画中画字幕、完整词典或网页整体翻译。
