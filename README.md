# Netflix 双语助手

为 Netflix 网页播放器提供原文与简体中文双语字幕、点击查词和本地生词本的 Chrome 扩展。默认使用 Chrome 本地翻译，可手动开启 MyMemory 在线备用，无需配置 API Key。

项目采用 Manifest V3 和原生 JavaScript，可直接加载源码目录，无需安装 npm 依赖、构建或启动服务。Node.js 仅用于开发测试。

## 主要功能

- **双语字幕**：原文在上、简体中文在下，支持自动识别或手动选择原字幕语言。
- **点击与划选查词**：点击原字幕中的词语，或拖选短句查看中文译文；查词时暂停播放，关闭后按原播放状态恢复。
- **本地生词本**：收藏词语、译文、原句、已有的原句译文、影片和播放位置，支持搜索、删除及导出 CSV / JSON。
- **字幕外观设置**：调整字号、背景不透明度和距画面底部的位置，支持网页全屏显示。
- **在线备用**：本地翻译不可用时，可使用手动授权的 MyMemory 服务。

## 快速开始

需要桌面版 Chrome 138 或以上，以及能够正常播放 Netflix 的浏览器环境。本地翻译的实际可用性取决于 Chrome 能力、语言对和语言包状态。

1. 下载并解压本项目，或将仓库克隆到本地。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的项目根目录。
4. 固定「Netflix 双语助手」，刷新已打开的 Netflix 页面。
5. 播放影片，在 Netflix 的音轨与字幕菜单中开启需要翻译的原文字幕，例如英语、日语或韩语。
6. 打开扩展弹窗，确认双语字幕已开启；自动识别不准确时，手动选择与原字幕一致的语言。
7. 如提示需要语言包，点击播放画面中的「准备本地翻译」，等待下载完成后显示中文译文。

首次使用本地翻译可能需要联网下载语言包。原字幕已是简体中文时，不会重复显示中文行；繁体字幕可手动选择「繁体中文」作为源语言。

更新源码后，在扩展管理页刷新本扩展，再刷新 Netflix 播放页。

## 设置与生词本

点击工具栏中的扩展图标调整设置，设置会保存在当前浏览器中。

| 设置 | 默认值 |
| --- | --- |
| 双语字幕 | 开启 |
| 原字幕语言 | 自动识别，目标语言为简体中文 |
| 字幕字号 | 26 px |
| 背景不透明度 | 65% |
| 距画面底部 | 10% |
| MyMemory 在线备用 | 关闭 |

点击或划选原字幕后，在查词浮窗中点击「收藏」。从播放画面或扩展弹窗打开生词本，即可搜索、删除或导出全部收藏；同一源语言下重复收藏同一词语会提示已收藏。

查词关闭时，只恢复由扩展暂停、且影片与播放位置仍符合恢复条件的视频；原本已暂停的视频保持暂停。

## 翻译与数据存储

默认通过 Chrome 本地翻译引擎处理字幕和查词文本。开启「MyMemory 在线备用」时，Chrome 会请求访问 `api.mymemory.translated.net` 的权限；本地翻译不可用时，扩展会将待翻译的字幕或词语发送给该服务，在线请求不携带 Cookie。

扩展按每天 5,000 字符限制并记录在线请求的本地估算量，按 UTC 日期重置。实际可用额度以服务端响应为准；失败或中断的请求也可能已消耗额度。关闭在线备用会停止当前在线请求并撤回域名权限。

设置和生词本保存在当前 Chrome 用户配置的 `chrome.storage.local` 中，不提供云端同步或导入功能。卸载扩展会删除本地数据，可通过生词本导出 CSV / JSON 留存。

## 支持范围

当前支持桌面 Netflix 网页中可读取的文字字幕及网页全屏，不包含图片字幕 OCR、音频识别、手机端、系统画中画字幕或完整词典功能。

扩展依赖 Netflix 原生字幕 DOM，页面结构变化可能需要更新适配。若同时启用了其他字幕扩展，请先关闭其字幕功能并刷新页面。下载失败、等待字幕和语言识别等问题见[安装与使用](docs/安装与使用.md)。

## 项目结构

```text
netflix-translate/
├── manifest.json          # 扩展配置、权限与内容脚本入口
├── background.js          # 在线翻译消息处理与生词存储操作
├── content/               # Netflix 字幕适配、字幕层与查词播放控制
├── lib/
│   ├── core.js            # 设置、语言、分词、缓存与导出工具
│   ├── translation.js     # 本地翻译、语言识别与任务调度
│   └── mymemory.js        # 在线请求、额度记录与取消处理
├── popup.html / popup.js  # 扩展设置弹窗
├── vocabulary.html / vocabulary.js  # 生词本页面
├── ui.css                 # 设置与生词本样式
├── scripts/               # 静态检查与本地测试服务器
├── tests/                 # 核心测试、浏览器模拟与真实引擎测试页
└── docs/                  # 安装使用、开发说明与验证记录
```

## 开发与验证

需要 Node.js 18 或以上。在项目根目录执行，无需先运行 `npm install`：

```sh
# 检查 Manifest 引用、内容脚本站点范围和脚本语法
npm run check

# 运行核心模块定向测试
npm test

# 启动仅监听本机的浏览器测试服务
npm run test:browser
```

测试服务默认监听 `127.0.0.1:8765`，可通过环境变量 `NT_TEST_PORT` 修改端口。

- [浏览器模拟测试](http://127.0.0.1:8765/watch/999)：打开后点击「运行浏览器测试」。
- [真实本地翻译引擎测试](http://127.0.0.1:8765/tests/local-engine.html)：调用 Chrome 实际翻译能力，首次使用可能需要下载语言包。

核心测试模拟网络请求和 Chrome 存储；浏览器模拟测试使用模拟视频与翻译响应。真实 Netflix 的字幕轨道、页面适配、播放控制和全屏效果需要单独验证。模块职责、处理流程和已有验证记录见[开发与验证](docs/开发与验证.md)。
